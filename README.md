# Chat App Documentation

## Overview
The Chat App allows real-time communication between users with features like text, video, and audio chat.

### Key Features
1. Real-time messaging
2. End-to-end encryption
3. Group chats
4. Video and audio calls
5. User roles and permissions

## User Guide
- **Login/Signup:** Users can register or log in with email credentials.
- **Chats:** Start a conversation by selecting a user or group.
- **Help & Support:** Navigate to the Help section from the main menu for assistance.

## Developer Guide
### Setup
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Run `npm start` to start the development server.
